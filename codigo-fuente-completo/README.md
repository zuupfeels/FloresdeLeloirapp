# Sistema de Gestión y Emisión de Legajos - Escuela Especial

## Cómo ejecutar en desarrollo
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar servidor local:
   ```bash
   npm run dev
   ```
   Abrir en el navegador: http://localhost:3000

## Cómo compilar para la web
```bash
npm run build
```
Los archivos compilados quedarán en la carpeta `dist/`, listos para subir a cualquier hosting estático (Netlify, Vercel, GitHub Pages, etc.).
